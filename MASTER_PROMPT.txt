1. GAME CONCEPT
==================================================

Create an original logic puzzle game based on placing one hidden item in each:

1. COLOR REGION
2. ROW
3. COLUMN

Additional mandatory rule:

4. ITEMS CANNOT TOUCH ORTHOGONALLY.

Therefore:

- An item cannot touch another item above it.
- An item cannot touch another item below it.
- An item cannot touch another item on its left.
- An item cannot touch another item on its right.

Diagonal touching IS allowed.

Every puzzle has a predetermined valid solution.

The normal game must NOT depend on random puzzle generation.

==================================================
2. NON-NEGOTIABLE COLOR REGION RULE
==================================================

THIS IS A CORE GAME RULE AND MUST NEVER BE VIOLATED.

EVERY COLOR MUST REPRESENT EXACTLY ONE CONNECTED REGION.

Definition:

1. Every color corresponds to ONE region.
2. All cells belonging to the same color MUST be connected through shared EDGES.
3. Diagonal contact DOES NOT count as connectivity.
4. A color may NOT appear as two or more separate/disconnected regions.
5. Every color region must contain EXACTLY ONE correct item in the official solution.
6. The number of color regions MUST equal the number of items in the solution.
7. Every region must have one and only one solution item.

Example of VALID region:

BLUE BLUE BLUE
BLUE BLUE
BLUE BLUE BLUE

All blue cells are connected through shared edges.

Example of INVALID region:

BLUE BLUE       BLUE
BLUE            BLUE

These blue cells form disconnected groups and MUST NOT be allowed.

Another INVALID example:

BLUE
    BLUE

Diagonal-only contact does NOT make a connected region.

==================================================
3. REGION VALIDATION ALGORITHM
==================================================

Before a level can be saved:

FOR EACH COLOR:

1. Find every cell having that color.
2. Select the first cell.
3. Perform a 4-direction flood-fill / BFS / DFS:
   - UP
   - DOWN
   - LEFT
   - RIGHT
4. Count all reachable cells.
5. Compare reachable-cell count with total cells of that color.

If:

reachableCells != totalColorCells

THEN:

LEVEL = INVALID

Discard the level.

A color is valid ONLY when all cells of that color are reachable from every other cell through shared edges.

==================================================
4. REGION + SOLUTION VALIDATION
==================================================

For EVERY color region:

solutionItemsInsideRegion MUST equal 1.

Therefore:

FOR EACH REGION:

    itemCount = number of solution items inside region

    if itemCount != 1:
        LEVEL = INVALID

The validator must check BOTH:

A. Region connectivity
B. Exactly one solution item per region

Both conditions are mandatory.

15. HINT SYSTEM — THREE DIFFERENT HINTS
==================================================

Create THREE genuinely different hint types.

------------------------------------------
HINT 1 — ITEM FINDER
------------------------------------------

Directly reveal ONE correct unresolved item.

When activated:

- choose one unresolved official solution position
- reveal it
- animate/highlight it
- mark it permanently solved
- update the puzzle state

Do not reveal the entire solution.

------------------------------------------
HINT 2 — IDEA TELLER / LOGIC HINT
------------------------------------------

Analyze the current board state and find a real logical deduction.

Examples:

"Blue already has an item in column 4, so the other blue cells in column 4 can be eliminated."

"Row 6 already contains an item, so the remaining cells in that row cannot contain another item."

"These are the only possible cells for the green region."

The hint must:

1. Analyze the current state.
2. Find an actual deduction.
3. Explain the deduction in simple language.
4. Highlight relevant cells.
5. Optionally apply the logical elimination automatically.

Do NOT show a random generic explanation.

The explanation must correspond to the actual current puzzle state.

------------------------------------------
HINT 3 — THREE-CELL REVEAL
------------------------------------------

Select THREE random unresolved cells.

For each selected cell:

- if it contains an official solution item, reveal the item
- otherwise reveal it as an empty/non-item cell

Do not select duplicate cells.

The selected cells must be unresolved before the hint.

This hint must never reveal more than three cells.
